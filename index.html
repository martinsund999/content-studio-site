Content Studio

A private production tool that researches, writes, narrates, illustrates and publishes cinematic documentary videos about extraordinary true stories to its owner's own YouTube channel.

Content Studio is a personal, non-commercial software project run by Martin Sund in Sweden. It connects to the YouTube Data API and YouTube Analytics API solely to manage the owner's own channel: uploading videos, scheduling their publication, setting titles, descriptions, captions and thumbnails, managing playlists, and reading the channel's own analytics.

The tool has no users other than its owner. It does not offer accounts, does not collect information from viewers, and does not access any channel other than the one its owner has explicitly authorised.

Narration in published videos is AI-generated and illustrations are artistic reconstructions. Each video is labelled accordingly on YouTube.
